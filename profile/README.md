# Indicia

> Search less, discover more.

We build software that helps security professionals, researchers, journalists, and investigators discover and connect available information publicly faster. Our products focus on making complex investigations simpler through modern tooling, APIs, AI, and automation.

---

## Open Source

This organization contains the official open-source projects maintained by the Indicia team, which include:

- SDKs
- CLI tools
